# OpenSC2K HD 그래픽

**udangtang7**이 제작·수정한 [nicholas-ochoa/OpenSC2K](https://github.com/nicholas-ochoa/OpenSC2K)용 커뮤니티 그래픽 팩입니다.

[English](README.md) · [그래픽 팩 다운로드](https://github.com/udangtang7/opensc2k-hd/releases/tag/hd-graphics)

이 저장소에는 **정적 이미지 499개, 애니메이션 스트립 62개, 스프라이트 연결 정보 1,448개**가 들어 있습니다. 엔진 개발과 언어 지원은 OpenSC2K에서 관리합니다.

## 적용 방법

1. [OpenSC2K 설치 안내](https://github.com/nicholas-ochoa/OpenSC2K#readme)에 따라 게임을 설치하고, 본인이 가진 원본 심시티 2000 자료를 가져옵니다.
2. 이 그래픽 팩을 다운로드하여 압축을 풉니다.
3. **설정 → 데이터 → HD 스프라이트 팩**에서 **`assets/pack.json`**을 선택합니다.
4. **설정 → 그래픽 → HD 그래픽**을 켭니다.

**HD 스프라이트 팩** 설정이 있는 OpenSC2K를 사용하세요. 별도 항목에 선택된 기존 원본 그래픽 팩은 유지합니다. 이 HD팩은 원본 게임 자료를 대체하지 않으며, 게임 실행 파일·원본 스프라이트·음악·효과음·텍스트 데이터를 포함하지 않습니다.

사용을 중단하려면 HD 그래픽을 끄거나 HD 스프라이트 팩 선택을 해제하세요.
